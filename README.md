# StormTrials · Штормовой архипелаг

Серверная мини-игра на выживание при стихийных бедствиях для **Minecraft Java Edition 1.21.11 и Paper**. Версия плагина хранится в [plugin.yml](resources/plugin.yml).

## Возможности

- 20 генерируемых арен и 30 катастроф. Постройки разрушаются в местах воздействий, а несущая платформа защищена.
- Автоматические раунды с 40-секундным перерывом, наблюдением, одним баффом и одним дебаффом. Можно поставить участие на паузу или перейти в AFK.
- Два аирдропа за полный раунд по умолчанию. 28 предметов можно изготовить из материалов или купить за монеты. Среди них семь постоянных аксессуаров.
- Статистика, достижения, анимации раунда, настраиваемое лобби и оформление TAB. Ресурспак добавляет модели предметов в игровых меню.

## Структура

| Путь | Содержание |
| --- | --- |
| `src/` | Плагин, генерация арен, катастрофы, снабжение и достижения |
| `resources/` | Дескриптор плагина, примеры игрового конфига и настройки TAB |
| `assets/` | Логотип и иконка списка серверов |
| `client/` | Node.js-сценарии интеграционной проверки |

## Сборка и запуск

Нужны PowerShell 7, JDK с поддержкой `--release 21` и хотя бы один раз запущенный Paper 1.21.11 с каталогом `libraries`. Собери JAR:

```powershell
./build-plugin.ps1 -PaperRoot "C:/path/to/paper"
```

На остановленном сервере замени предыдущий JAR StormTrials в `plugins/` новым файлом из `dist/`. При обновлении сохраняй мир `storm_islands` и `plugins/StormTrials/config.yml`. Пример чистого конфига находится в `resources/stormtrials.example.yml`. EssentialsX, EssentialsXSpawn и TAB используются в развёртывании сервера.

Для сборки опционального ресурспака передай локальный клиентский JAR Minecraft 1.21.11. ZIP можно включить через меню «Наборы ресурсов».

```powershell
./build-model-pack.ps1 -ClientJar "C:/path/to/1.21.11.jar" -Output "./dist/Storm-Archipelago-Models.zip" -Icon "./assets/server-icon.png"
```

## Команды

- `/storm shop` — купить снаряжение. `/storm kit` — открыть верстак в раунде.
- `/storm accessories` — выбрать аксессуар. `/storm achievements` — открыть достижения.
- `/storm maps`, `/storm disasters` — показать карты и стихии.
- `/storm pause`, `/storm afk`, `/storm join` — управлять участием.
- `/storm build`, `/storm setlobby` — строить лобби и установить точку появления.

## Текущие ограничения

Внешний адрес бесплатного туннеля меняется при переподключении. Ресурспак включается вручную. Архив и идентификаторы моделей проверены, визуальная проверка всех моделей в Minecraft ещё предстоит. Подробности и статус испытаний см. в [DEVELOPMENT.md](DEVELOPMENT.md).
